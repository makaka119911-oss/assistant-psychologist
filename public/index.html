Zoom / Телемост — как слышать клиента
  • Не тестируйте на YouTube — фразы теряются из‑за эха, это не звонок.
  • С наушниками без кабеля Chrome слышит только вас, не клиента.
  • Лучше: VB-Cable + CABLE Output в списке выше.
  • Проще: колонки + Stereo Mix (если есть в Windows).
  • Сначала «Начать приём», потом войти в Zoom / Телемост.
