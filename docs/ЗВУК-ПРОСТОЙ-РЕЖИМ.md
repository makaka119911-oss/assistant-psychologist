# Звук без кабеля (если Voicemeeter не пишет клиента)

Chrome плохо распознаёт речь из виртуального кабеля. **Простой режим** часто работает надёжнее.

## Настройка

1. **Voicemeeter** можно закрыть (или не трогать).
2. **Windows → Звук → Ввод:** `Микрофон (Realtek)`.
3. **Zoom → Динамик:** `Динамики (Realtek)` — не CABLE.
4. **Zoom → Микрофон:** Realtek.
5. Телефон в Zoom: говорит **громко**, ноутбук на столе, **без наушников на ноуте** (или тихо в колонках).

Оба голоса попадают в один микрофон через воздух.

## Проверка в ассистенте

«Начать приём» → полоска **«Вход в Chrome»** должна двигаться, когда говорит **и вы, и телефон**.

## Если эхо

Наушники на ноуте + громкая связь на телефоне в другой комнате / тише колонки.
