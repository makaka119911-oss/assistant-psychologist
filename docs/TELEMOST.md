# Звук с Яндекс Телемост (и других звонков)

Приложение слушает **микрофон Windows**. Чтобы в расшифровку попадала речь **клиента** с видеозвонка, нужно подать в микрофон системный звук звонка (или отдельный виртуальный кабель).

## Вариант 1: VB-Audio Cable (рекомендуется)

1. Установи [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) (бесплатно).
2. В Телемост / Windows выбери **вывод звука** → `CABLE Input`.
3. В Chrome на сайте ассистента при «Начать слушать» выбери **микрофон** → `CABLE Output`.
4. Громкость звонка — средняя, без эха (наушники у психолога — лучше).

Клиент слышит вас через обычный микрофон в Телемост; ассистент слышит только то, что идёт в кабель (голос клиента из звонка).

## Вариант 2: Stereo Mix

Если в драйвере звуковой карты есть **Stereo Mix**:

1. Включи Stereo Mix в параметрах записи Windows.
2. Выбери Stereo Mix как микрофон в Chrome.

Минус: может захватывать лишние звуки с ПК.

## Вариант 3: Телефонный звонок

- Громкая связь рядом с микрофоном ноутбука (качество хуже).
- Или запись разговора на телефон → потом вставить текст вручную (в будущих версиях можно добавить загрузку файла).

## Важно

- Используйте **Chrome** — Web Speech API лучше всего работает там.
- Первый раз Chrome спросит разрешение на микрофон.
- Расшифровка идёт в облако браузера (Google), анализ — в DeepSeek по вашему API-ключу.
- Предупредите клиента о записи/обработке речи, если это требуется вашей этикой и законом.
