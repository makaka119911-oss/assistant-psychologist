# Входящий звонок на Android — как добиться чёткой расшифровки

## Главное ограничение

Обычное приложение **не может** записать «провод» сотового звонка (как встроенная запись звонков на некоторых Samsung/Xiaomi).  
Оно слушает **микрофон телефона**.

Поэтому для **входящего вызова** нужен режим **громкой связи**.

---

## Правильный порядок (лучший результат)

1. **До звонка** откройте приложение «Ассистент психолога» (APK, не Expo Go).
2. Включите **«Режим звонка»** (переключатель на экране Приём).
3. Нажмите **«Начать приём»** — разрешите микрофон.
4. Примите **входящий** вызов.
5. Сразу включите **громкую связь** (динамик).
6. Положите телефон экраном вверх на стол — микрофон не закрывайте пальцем.
7. Говорите как обычно; клиент слышен из динамика → микрофон ловит обоих.
8. После разговора — **«Закончить»** в приложении (вернитесь в приложение из звонка).

> Если сначала ответить на звонок, а потом открыть приложение — микрофон часто уже занят, расшифровка будет пустой или обрывистой.

---

## Настройки телефона

| Настройка | Зачем |
|-----------|--------|
| **Не** «Экономия батареи» для приложения | Иначе запись оборвётся |
| Разрешение **микрофон** — всегда | Обязательно |
| Уведомления — разрешить | Пока идёт приём, висит «Запись приёма» |
| Громкость медиа — средняя/выше | Тихий динамик = плохой текст |

**Samsung:** подробно → [SAMSUNG.md](./SAMSUNG.md) (батарея, громкая связь, запись звонков).

Xiaomi: «Не оптимизировать» / «Без ограничений» для приложения.

---

## Если текст всё равно плохой

| Причина | Что сделать |
|---------|-------------|
| Без громкой связи | Только наушник с микрофоном **или** громкая связь |
| Начали запись после ответа | Перезвоните и следуйте порядку выше |
| Шум, улица | Тише помещение, ближе к телефону |
| Долгий звонок, пропали фразы | Нажмите **«Разбор сейчас»** вручную — разбор по уже записанному |
| Пустая расшифровка | Аудио всё равно в сессии — позже можно добавить ручной ввод (в разработке: разбор по файлу) |

## Надёжнее, чем один телефон

| Вариант | Качество |
|---------|----------|
| **2 устройства**: звонок на телефоне, приложение на планшете рядом | ★★★★★ |
| 1 телефон + громкая связь + режим звонка | ★★★☆☆ |
| Звонок в WhatsApp/Telegram на громкой | ★★★★☆ (часто лучше, чем GSM) |
| Наушники с микрофоном (вы в наушниках, клиент в эфире) | ★★★☆☆ |

## iPhone

Входящий сотовый звонок + то же приложение на iPhone **почти не работает** (ограничения Apple).  
Для iPhone: планшет Android рядом или приём на ПК в браузере.
