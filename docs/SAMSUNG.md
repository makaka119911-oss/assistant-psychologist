# Samsung (One UI) — настройка для приёма по звонку

## Главное

На Samsung приложение работает так же: **микрофон + громкая связь**.  
Отдельно: на многих Samsung есть **встроенная запись звонков** — ею можно пользоваться параллельно, а наш ассистент даёт **разбор для психолога**.

---

## Перед первым приёмом (один раз)

### 1. Разрешения

**Настройки** → **Приложения** → **Ассистент психолога** → **Разрешения**

| Разрешение | Значение |
|------------|----------|
| Микрофон | **Разрешить всегда** |
| Уведомления | Разрешить |

### 2. Батарея (очень важно на Samsung)

**Настройки** → **Приложения** → **Ассистент психолога** → **Батарея**

- Режим: **Без ограничений** (Unrestricted)
- **Разрешить фоновую активность** — вкл.
- **Разрешить работу при закрытых приложениях** — вкл. (если есть)

Дополнительно:

**Настройки** → **Уход за устройством** → **Батарея** → **Ограничения фона**

- Уберите приложение из **«Спящих»** и **«Глубокого сна»** (Deep sleeping apps).

### 3. Установка APK

Не Expo Go — только собранный **APK** (см. `MOBILE-PHONE.md`).

При установке: **Настройки** → безопасность → разрешить установку из этого источника (Chrome / «Мои файлы»).

---

## Входящий звонок — порядок

1. Откройте **Ассистент психолога**
2. Включите **«Режим звонка»**
3. **«Начать приём»**
4. Примите звонок
5. В звонке нажмите **«Динамик»** (громкая связь) — иконка динамика
6. Громкость **медиа** поднимите (кнопки сбоку — не «звонок», а музыка/медиа)
7. После разговора откройте приложение из списка недавних → **«Закончить»**

Не сворачивайте приложение в «закрыть все» во время приёма.

---

## Запись звонков Samsung (опционально)

На части моделей (зависит от страны и прошивки):

**Телефон** → **⋮** → **Настройки** → **Запись вызовов**

Если есть — можно **дополнительно** записывать звонок в память телефона.  
Наш ассистент всё равно нужен для **текста и разбора** — встроенная запись не делает анамнез.

---

## Если плохо слышит / пустой текст

| Проверка | Действие |
|----------|----------|
| Ответили до «Начать приём» | Перезвоните, сначала приложение |
| Громкая связь выкл. | Включить динамик в звонке |
| Экономия звука | **Настройки** → **Звуки** → отключить «Адаптация звука» на время приёма (если мешает) |
| Bluetooth наушники | Отключить BT — иначе микрофон в наушниках, клиент не слышен |
| Bixby / «Оптимизация» | Не убивать приложение в «Уход за устройством» |

## Модели и регион

- **Россия / СНГ**: встроенная запись звонков часто **есть** на Galaxy A/S серии (не на всех).
- Если записи звонков в меню нет — это норма, используйте только наш сценарий с **громкой связью**.

---

## Лучший вариант на Samsung

**Galaxy Tab** или старый телефон рядом: на нём только ассистент, на Samsung — обычный звонок с громкой связью. Качество расшифровки выше, чем с одного аппарата.
