# Приложение на телефон (Android)

Веб-сайт в браузере телефона **не подходит** для приёма (особенно во время звонка). Нужно **установить APK**.

## 1. Собрать APK (один раз, на вашем ПК)

```powershell
cd "c:\Users\Ягодка\Desktop\my project\Ассистент психолог"
npm run assets
npm install
npm install -g eas-cli
eas login
eas build:configure
npm run eas:apk
```

Через 10–20 минут появится ссылка на **APK** — скачайте и отправьте на телефон (Telegram / почта).

Установка: разрешить «неизвестные источники».

> **Expo Go не подходит** — нет нормального распознавания речи. Только APK.

## 2. Настройка на телефоне

1. Откройте приложение **Ассистент психолога**
2. **Настройки** → «Проверить связь» → должно быть `✓ AI готов`
3. Адрес сервера по умолчанию: `https://assistant-psychologist-eosin.vercel.app` (ПК не нужен)
4. Свой ключ Cerebras — только если свой сервер

## 3. Как вести приём

| Ситуация | Как |
|----------|-----|
| Клиент в кабинете | Телефон на столе, «Начать приём» |
| Звонок клиенту с этого же телефона | **Громкая связь**, потом в приложении «Начать приём» (микрофон слышит обоих) |
| Звонок + плохая расшифровка | Лучше **второй телефон/планшет** только под ассистента |
| Нет интернета | Запись сохранится → **История** → «Анализ» позже |

## 4. После сессии

- **История** — все приёмы на телефоне
- **Экспорт PDF** — в карточке сессии
- На ПК можно дублировать заметку через веб → кнопка **Obsidian**

## iPhone

Сборка на iPhone сложнее (нужен Mac + Apple Developer). Для iOS пока: iPad/Android или веб на ПК.
